# AUTOPILOT FOCUS
- Automatically detects distractions and blocks them.
- Most distraction blockers you need to manually setup your distractiong websites
- If you visit a site that is distracting and not in your block list you get distracted.
- Some sites like youtube can be a source of your study and also a distraction. Most distraction blokers simply block whole domains so if youtube is blocked you cannot study and if it isn't blocked you can get distracted.
- So to solve this problem Autopilot Focus makes use of context aware model to detect distractions and block them
